# 《明朝那些事儿》候选池：术语

| 术语 | 作者用法 | 可迁移意义 |
|---|---|---|
| 历史 | 可读的人物与事件链 | 知识传播入口 |
| 权力 | 实际影响组织行动的能力 | 管理与政治分析核心 |
| 制度 | 反复塑造行为的结构 | 判断问题是不是个人造成 |
| 时机 | 资源和局势共同成熟的窗口 | 决策触发条件 |
| 资本 | 地盘、人才、名义、军队、情报等资源 | 行动前的储蓄 |
| 党争 | 理念、人事、利益和安全感混合斗争 | 组织派系风险 |
| 信息过滤 | 上层接触到的事实被层层改变 | 领导风险 |
| 末代管理者 | 接手存量危机却不断误判的人 | 危机领导警戒 |
