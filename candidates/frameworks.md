# 《明朝那些事儿》候选池：框架

## f01 人物位置判断

```yaml
id: f01
title: 人物位置判断
type: framework
source_chapter: 全书人物线
source_quote: "以年代和具体人物为主线。"
summary: |
  分析人物时不先贴好坏标签，而先看他的位置、资源、对手、约束和目标。
  这个框架可迁移到组织分析、管理判断和历史人物讨论。
tags: [actor-analysis, history, management]
```

## f02 权力结构诊断

```yaml
id: f02
title: 权力结构诊断
type: framework
source_chapter: 内阁、宦官、文官、皇权多线叙事
source_quote: "真正让他畏惧的，是这份奏折的落款——六部九卿。"
summary: |
  区分名义权力、实际权力、信息权力、执行权力和否决权。
  很多事件不是谁对谁错，而是谁能调动哪些系统资源。
tags: [power, organization, structure]
```

## f03 储蓄资本与出手时机

```yaml
id: f03
title: 储蓄资本与出手时机
type: framework
source_chapter: 朱元璋篇
source_quote: "等待最好的时机。"
summary: |
  行动前先储蓄资源、盟友、情报、名义和组织能力。
  真正的出手不是情绪爆发，而是条件成熟后的集中行动。
tags: [timing, strategy, resource]
```

## f04 制度失灵识别

```yaml
id: f04
title: 制度失灵识别
type: framework
source_chapter: 锦衣卫、内阁、财政、边防与晚明
source_quote: "很多事情只要开了头，就很难收尾了。"

tags: [system, incentives, failure]
```

## f05 信息失真防线

```yaml
id: f05
title: 信息失真防线
type: framework
source_chapter: 皇帝、内阁、宦官、言官关系
source_quote: "没有人能猜透他的心思。"
summary: |
  高层越强势，身边越容易形成过滤层。
  需要主动建立反向信息、异议通道和事实校验。
tags: [information, leadership, risk]
```

## f06 末代管理者警戒

```yaml
id: f06
title: 末代管理者警戒
type: framework
source_chapter: 朱由检篇
source_quote: "所谓胜利，是可以算出来的。"
summary: |
  在存量危机中，勤奋不等于有效；如果不断更换方案、怀疑所有人、只追求短期止血，会加速系统崩溃。
tags: [crisis, leadership, decision]
```
