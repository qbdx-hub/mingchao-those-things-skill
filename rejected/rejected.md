# 《明朝那些事儿》淘汰或降级单元

## 先看结构，再评人品

- 结果: 合并进 `人物位置判断`
- 原因: 它是 f01 的原则表达, 不需要独立 skill。

## 开了口子的权力会自我扩张

- 结果: 合并进 `制度失灵识别`
- 原因: 作为制度失灵的警示模式保留, 单独成 skill 容易变成口号。

## 胜利要先算出来

- 结果: 合并进 `储蓄资本与出手时机` 和 `末代管理者警戒`
- 原因: 独立性不足, 且容易被误解成权谋技巧。

## 好故事不等于最终史论

- 结果: 降级为总边界
- 原因: 这是使用全书的阅读边界, 不是一个可执行 skill。

## 派系风险分析

- 结果: 暂不独立成 skill
- 原因: 当前候选容易退化为通用办公室政治分析, 先并入 `权力结构诊断`。
